
结合 YOLO 检测范式与多模态大模型的开放词汇目标检测实现，通过图文特征深度对齐，实现零样本 / 小样本类别无关检测，无需重新训练主干网络即可快速适配新类别目标，兼顾检测精度与工程实用性。

本项目基于 **FG-CLIP** 多模态基础模型构建，主干网络与图文特征提取能力引用自：
https://github.com/360CVGroup/FG-CLIP


## 📌 环境配置

### 基础环境

Python 3\.8\+、PyTorch 1\.10\+、CUDA 11\.3\+（建议 GPU 训练，CPU 可运行但速度较慢）

### 依赖安装

```bash
pip install torch torchvision pillow transformers tqdm
```


## 📊 数据准备

### 数据集结构

建议使用数据集LVIS。

采用自定义 YOLO 格式数据集，目录结构如下：

```plain
custom/
├─ images/          # 图像文件（train/val子目录，可选）
│  ├─ train/
│  └─ val/
├─ labels/          # 标签文件（与图像一一对应，txt格式）
│  ├─ train/
│  └─ val/
└─ data.txt         # 类别名称文件（每行一个类别，如：0: cat、1: dog、2: car）
```

## 🚀 模型训练

### 训练步骤

1. 从 **FG-CLIP** 项目获取预训练多模态模型（fgmodel），放入主脚本同级fgmodel名称的目录。modeling_fgclip2.py文件不要替换。

2. 配置数据集路径：在主脚本同级目录创建custom目录，将数据集按目录结构放入。

3. 运行主脚本：

```bash
python train.py
```

## 🔧 核心代码解析

### 1\. 模型结构

- **AdaptedDetectHead**：自定义检测头，包含 box\_head（边界框回归）和 cls\_head（类别预测）双分支，通过图文相似度计算生成特征掩码，优化特征提取。

- **CustomYOLOLoss**：自定义损失函数，融合 CIoU 损失（边界框回归）和 Varifocal 损失（类别预测），适配开放词汇检测场景。

### 2\. 关键功能

- **文本特征缓存**：首次运行计算所有类别文本特征并缓存，避免重复计算，提升效率。

- **图文特征对齐**：通过矩阵乘法计算图像特征与文本特征的相似度，生成特征掩码，强化目标区域特征。

- **高斯模糊的核心作用**：本项目中高斯模糊（gauss\_kernel）分别应用于 AdaptedDetectHead（检测头）和 CustomYOLOLoss（损失函数），是图文注意力机制实现的关键支撑，具体作用分为两点：一是在检测头中，对图文相似度生成的 sim\_max（注意力权重图）进行平滑处理，消除相似度计算中因像素级噪声、特征波动导致的权重突变，让注意力权重呈现 “中心强、边缘弱” 的自然过渡，贴合高斯函数 “距离越近、影响越大” 的核心特性，精准聚焦目标区域，避免注意力误聚焦到背景冗余特征上；二是在损失函数中，对文本相似度掩码（text\_mask）进行平滑，缓解正负样本权重分配的极端差异，避免模型训练过程中因注意力权重骤变导致的训练震荡，提升模型收敛稳定性。与普通均值模糊（盒式模糊）相比，高斯模糊通过正态分布加权实现平滑过渡，不会出现生硬的权重断层，能最大程度保留目标区域的注意力特征完整性。

- **高斯模糊在注意力机制中的必要性**：结合本项目的图文注意力逻辑（通过图文相似度生成注意力权重，引导特征提取和损失计算），高斯模糊的必要性可从三个核心维度推断：① 解决注意力权重噪声问题：图文相似度计算易受图像纹理干扰、文本特征微小偏差影响，产生离散的高权重噪声点，高斯模糊通过 3×3 高斯卷积核对权重图进行加权平滑，可有效过滤噪声，确保注意力权重的连续性，这是注意力机制精准定位目标的基础；② 契合注意力机制的 “全局关联性” 需求：注意力机制的核心是捕捉目标区域的全局特征关联，高斯模糊的可分离卷积特性的本质是实现局部特征的加权融合，让目标区域内的注意力权重相互关联，避免孤立权重点导致的目标定位碎片化，同时其归一化特性可确保权重平滑后不改变整体权重分布，避免特征失真；③ 保障训练稳定性：注意力机制的权重分配直接影响模型的特征学习和损失计算，若权重波动过大，会导致模型训练震荡、泛化能力下降，高斯模糊通过平滑权重梯度，让注意力权重的更新更平缓，帮助模型快速收敛，同时强化目标区域与背景的区分度，让注意力机制能更稳定地发挥 “聚焦有用特征、抑制冗余特征” 的核心作用，这也是开放词汇检测场景中，模型能精准匹配图文特征的关键前提。
